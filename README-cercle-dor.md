# 🟡 Cercle d'Or
### *Commencez par le Pourquoi.*

**Cercle d'Or** est un outil interactif basé sur le framework **Golden Circle de Simon Sinek** — la méthode qui explique pourquoi certaines organisations et certains leaders inspirent là où d'autres n'y arrivent pas.

🔗 **Site en ligne :** [razouzou44.github.io/cercle-dor](https://razouzou44.github.io/cercle-dor/)

---

## 💡 La méthode

> *"Les gens n'achètent pas ce que vous faites, ils achètent pourquoi vous le faites."*
> — Simon Sinek, *Start With Why*

Le Cercle d'Or repose sur 3 niveaux de communication, de l'intérieur vers l'extérieur :

| Niveau | Question | Ce que c'est |
|---|---|---|
| 🔴 **POURQUOI** | Pourquoi existez-vous ? | Votre conviction, votre raison d'être |
| 🟠 **COMMENT** | Comment le faites-vous ? | Vos valeurs et différenciateurs |
| 🟡 **QUOI** | Quoi faites-vous ? | Vos produits et services |

La plupart des organisations communiquent de l'extérieur vers l'intérieur (Quoi → Comment → Pourquoi). Les marques qui inspirent font l'inverse.

## 🧰 Fonctionnalités

### 🎯 Cercle d'Or interactif
- Trois anneaux concentriques cliquables (Pourquoi / Comment / Quoi)
- Panneau d'édition contextuel par section
- Indicateurs de complétion visuels
- Thème clair / sombre

### 🔍 Wizard — Découvrir son Pourquoi
- 5 questions guidées par la méthode Sinek
- Génération automatique de la formule Pourquoi
- Transfert en un clic vers le Cercle d'Or

### 💬 Générateur de messages
- **Pitch 30 secondes** — pour le networking et les réunions
- **Accroche courte** — pour les réseaux sociaux et la bio
- **Introduction de présentation** — pour ouvrir un pitch ou une conférence
- Bouton copier pour chaque format

### 💡 Inspirations
- Apple, Nike, Martin Luther King, Tesla
- Leur Pourquoi / Comment / Quoi analysés et interactifs
- Bouton "Utiliser comme modèle" pour s'en inspirer

### 📄 Export PDF
- Rapport complet : Cercle d'Or + pitch + réponses du wizard

---

## 🚀 Utilisation

Aucune installation requise. Ouvrez directement dans un navigateur.

1. **Commencez par le Pourquoi** — remplissez le centre du cercle en premier
2. **Complétez le Comment** — vos valeurs et principes en action
3. **Ajoutez le Quoi** — vos offres visibles
4. **Générez votre message** — pitch prêt à l'emploi
5. **Exportez en PDF** — pour partager ou présenter

Les données restent **100 % en local** — rien n'est envoyé.
